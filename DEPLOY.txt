REPLACING YOUR REPO CONTENTS WITH THIS FOLDER
=============================================

The contents of this folder ARE the repository root. Copy everything
inside it (not the folder itself) into your local clone.

Old files that must be DELETED from the repo root — copying alone will
not remove them:

    thank-you.html
    assets/            (the whole folder: cover.jpg, cover-large.jpg)
    DESIGNER-NOTES.md
    RAZORPAY-SETUP.md

Those now live under money-reset/ instead.

Commands
--------

    cd iashishbhandari.github.io
    git rm -r thank-you.html assets DESIGNER-NOTES.md RAZORPAY-SETUP.md
    cp -R /path/to/grubbite-site-root/. .
    cp /path/to/grubbite-site-root/.nojekyll .      # hidden file, copy it explicitly
    git add -A
    git status                                       # check before committing
    git commit -m "Move ebook to /money-reset/, add GrubBite homepage"
    git push
